# eerie_model_eddies
In this repo you can find the .ipynb associated with paper "Ocean mesoscale eddies in kilometer-scale climate models" by Bērziņa et al. 2026 (in prep).

Included notebooks:
1. Eddy indentification with py-eddy-tracker
2. Preprocessing of py-eddy-tracker output for eddy fluctuating kinetic energy FKE calculation
3. Eddy FKE calculation (decomposition)
4. Eddy intensity (conditional mean) calculation
5. Daily FKE calculation from model and observational data

Data used in this analysis can be founf on EERIE cloud (https://discover.dkrz.de/external/stac2.cloud.dkrz.de/fastapi/collections/eerie), the indentified eddies for each of the models (ICON, IFS-NEMO, IFS-FESOM, HADGEM) and observations can be found on zenodo (https://doi.org/10.5281/zenodo.23498667).
