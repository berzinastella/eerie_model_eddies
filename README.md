# eerie_model_eddies
In this repo you can find the .ipynb associated with paper "Ocean mesoscale eddies in kilometer-scale climate models" by Bērziņa et al. 2026 (in prep).

Included notebooks:
1. Eddy indentification with py-eddy-tracker
2. Preprocessing of py-eddy-tracker output for eddy fluctuating kinetic energy FKE calculation
3. Eddy FKE calculation (decomposition)
4. Eddy intensity (conditional mean) calculation
